NORTHSTAR BANK — ОБНОВЛЕНИЕ ИНТЕРФЕЙСА

Это обновление для УЖЕ РАБОТАЮЩЕГО проекта bank-frontend.

ИЗМЕНЕНИЯ
- Вместо «Лекция 9» появился банковский раздел «Аналитика и доступ».
- Убраны учебные заголовки, PDF-кнопка и SQL-примеры со страницы.
- Три раздела: Клиенты и счета / Филиальная сеть / Роли и доступ.
- Роли открываются отдельно от SQL Views, даже если отчёты ещё не настроены.
- Новая миграция database/bank_analytics.sql безопасна для существующих банковских записей.

КАК УСТАНОВИТЬ НА MAC
1. В VS Code останови сайт и API через Control+C в их терминалах.
2. Сделай резервную копию всей папки bank-frontend, включая .env.
3. Открой терминал именно в папке bank-frontend.
4. Распакуй ZIP поверх проекта:

   unzip -o ~/Downloads/Northstar_Bank_Professional_Update.zip -d .

5. Удали больше не используемые учебные файлы (эти команды не затрагивают базу):

   rm -f src/Lecture9Page.jsx public/Lecture9.pdf

6. Применить SQL для банковской аналитики:

   psql -U postgres -h localhost -p 5432 -d bank_database -v ON_ERROR_STOP=1 -f database/bank_analytics.sql

   Введи пароль PostgreSQL.

7. Запусти API в первом терминале:

   npm run server

8. Запусти сайт во втором терминале:

   npm run dev

9. Открой http://localhost:5173 и выбери «Аналитика и доступ» → «Роли и доступ».

ВАЖНО
- Файл .env не включён в ZIP и не будет заменён.
- Сама база bank_database не сбрасывается и не удаляется.
- Если у тебя другие названия базы или настройки, используй свои значения.
- Список ролей показывается только для просмотра.
