NORTHSTAR BANK — выпадающий список страниц

Применять после Northstar_Bank_Pagination_Update.zip.

1. В VS Code открой терминал в папке банковского проекта с package.json.
2. Скачай этот ZIP в Downloads.
3. Распакуй:
   unzip -o ~/Downloads/Northstar_Bank_Page_Dropdown_Update.zip -d .
4. Запусти:
   python3 apply_page_dropdown.py
5. Обнови браузер (Cmd+R). Если сайт не запущен: npm run dev.

Изменение: в «Транзакции» вместо поля с цифрой и кнопки «Перейти» появится список всех доступных страниц. Выбор страницы сразу переключает список.

Никаких SQL-команд не требуется. API, роли и балансы не меняются.
Скрипт проверяет код перед заменой и сохраняет резервную копию исходных файлов в соседней папке.
